# Contributing
Use Node 22 and npm. Run `npm install`, `npm test`, `npm run build`.
All contributions require the Developer Certificate of Origin 1.1:
https://developercertificate.org/. By adding `Signed-off-by: Your Name <email>`
you certify the DCO. Use `git commit -s` with your own identity.
Keep OSS pipeline features usable without a license. Never commit license keys,
private signing keys, provider credentials or user media. Tests use generated keys.
